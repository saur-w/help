
# 📅 Meu Dia
[Acesso: https://saur-w.github.io/help/]

Um aplicativo web simples para organização diária e acompanhamento de evolução profissional. Desenvolvido para pessoas que precisam de uma ferramenta visual, focada e que funcione offline.

## ✨ Funcionalidades

### 📋 Planejamento Diário
- **Brain Dump Matinal** — Despeje tudo que está na cabeça antes de começar o dia
- **Entrada por voz** — Fale ao invés de digitar (reconhecimento de voz em português)
- **3 Tarefas do Dia** — Foco no que realmente importa (com destaque para a mais importante)
- **Post-it Mental** — Uma tarefa de cada vez, visível na sua frente
- **Itens Blocked** — Tire da cabeça o que não depende de você
- **Vitória do Dia** — Registre suas pequenas conquistas (Brag Document)

### 📆 Planejamento Semanal
- 7 tarefas da semana com datas
- Itens blocked com responsável e data de acionamento
- Conquistas da semana (Brag Document)
- Checklist de comunicação

### 📊 Acompanhamento de Progresso
- **Calendário visual** — Veja quais dias você preencheu
- **Estatísticas** — Dias ativos, tarefas concluídas, sequência atual
- **Lembretes automáticos**:
  - Toda sexta-feira: Brag Document + Backup
  - A cada 15 dias: Revisão de evolução
- **Revisão quinzenal** — Autoavaliação em 5 áreas de desenvolvimento
- **Histórico de revisões** — Acompanhe sua evolução ao longo do tempo

### 💾 Seus Dados
- **100% local** — Dados salvos apenas no seu navegador (localStorage)
- **Exportar/Importar** — Faça backup em arquivo JSON
- **Privacidade total** — Nada é enviado para servidores

## 🚀 Como Usar

### Opção 1: GitHub Pages
Acesse diretamente: [seu-usuario.github.io/meu-dia](https://seu-usuario.github.io/meu-dia)

### Opção 2: Local
1. Clone o repositório ou baixe o arquivo `index.html`
2. Abra no navegador (Chrome recomendado para reconhecimento de voz)

### Dica: Usar como "App"
No Chrome:
1. Acesse a página
2. Menu (⋮) → "Mais ferramentas" → "Criar atalho"
3. Marque "Abrir como janela"
4. Pronto! Abre como um app separado

## 📱 Compatibilidade

- ✅ Tablet

- ⚠️ Reconhecimento de voz funciona melhor no Chrome

## 🔒 Privacidade

Este app foi criado com privacidade em mente:

- **Sem backend** — É apenas um arquivo HTML
- **Sem cookies de rastreamento**
- **Sem analytics**
- **Dados ficam no SEU navegador** — Cada dispositivo tem seus próprios dados
- **Repositório público é seguro** — O código é só o "esqueleto"; suas anotações ficam localmente

## 💡 Metodologia

O app foi desenvolvido baseado em princípios de produtividade para pessoas com TDAH e sobrecarga mental:

1. **Simplicidade radical** — Quanto menos decisões, melhor
2. **Visual primeiro** — Informação que o olho bate e vê
3. **Uma coisa de cada vez** — Post-it mental para foco
4. **Blocked é blocked** — Tire da cabeça o que não depende de você
5. **Celebre pequenas vitórias** — Brag Document diário
